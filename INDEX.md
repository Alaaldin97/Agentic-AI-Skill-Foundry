## Dev Tools

### [skill-reviewer](skills/skill-reviewer/)

Review an agent skill before it is submitted or merged. Use when the user asks to review a skill, check a SKILL.md, audit a skill's description, work out why a skill is not firing, why a skill fires on the wrong prompts, or whether a skill is ready to open a pull request against The Skill Foundry.

> **Does not fire on:** reviewing ordinary source code, reviewing a pull request that contains no SKILL.md, or writing a brand-new skill from scratch.
