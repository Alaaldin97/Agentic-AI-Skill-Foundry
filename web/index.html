How to add yours

Skills ship as pull requests, not issues — an issue is a conversation that gets closed, a PR is files that get merged and stay installable.

1 Branch & copy

git checkout -b skill/my-skill then copy skills/_TEMPLATE.

2 Build & run it

Test it on a real task. You need a transcript — a description of one will not pass.

3 Prove both directions

That it fires on the symptom, and that it stays quiet on a near-miss.

4 Validate, push, review

python scripts/validate_skill.py — then open the PR and review someone else's.

That validator is a gate, not a suggestion. The same script runs in CI and blocks the merge if it fails. A rule in prose is advisory; a rule in code is enforced — which is the whole lesson of Module 5B, applied to the repo you are contributing to.
